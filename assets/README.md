# Convert mermaid diagram to SVG

For some reason VSCode markdown viewer do not show some mermaid diagrams,
so I have converted it to svg.

To convert mmd to svg you can use online tool like this one:
[Mermaid Online](https://www.mermaidonline.live/mermaid-to-svg)

Or use cli tool like this: [mermaid-cli](https://github.com/mermaid-js/mermaid-cli)
